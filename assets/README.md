# Grafiki repozytorium

`banner.svg` jest banerem README. W `icons/` znajdują się autorskie oznaczenia Filman, AnimeWatch, AnimeGate, Ekino TV oraz repozytorium.

Każda ikona ma edytowalne źródło SVG i odpowiadający mu PNG 512 × 512 px używany w katalogu CloudStream. Po zmianie SVG wyeksportuj PNG w tym samym rozmiarze, zachowując przezroczystość narożników. Nazwy plików i adresy `iconUrl` są używane przez zainstalowane dodatki.

ObejrzyjTo zachowuje ikonę i opis pobrane z oryginalnego katalogu Phisher98.
