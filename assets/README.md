# Grafiki repozytorium

## Oryginalne ikony serwisów

Ikony używane w katalogu CloudStream i tabeli README pochodzą z deklaracji `rel="icon"` na stronach serwisów. Pobrane pliki PNG zachowują oryginalne bajty, rozmiar i przezroczystość. Rozszerzenie `.ico` w adresie AnimeGate również zwraca plik PNG.

| Serwis | Źródło ikony | Rozmiar |
| --- | --- | --- |
| Filman | [favicon.png](https://filman.cc/public/dist/images/favicon.png) | 128 × 128 px |
| AnimeWatch | [cropped-IKONA-192x192.png](https://animewatch.pl/wp-content/uploads/2025/11/cropped-IKONA-192x192.png) | 192 × 192 px |
| AnimeGate | [favicon.ico](https://animegate.pl/favicon.ico?favicon.2m3wqda9mskab.ico) | 32 × 32 px |
| Ekino TV | [shortcut.png](https://ekino.ws/views/img/shortcut.png) | 20 × 20 px |

Kopie są przechowywane w `icons/*-site.png`, aby CloudStream i README mogły pobrać grafikę bez cookies i logowania. [Datę pobrania, adresy oraz sumy SHA-256](icon-sources.json) zapisano obok. Nazwy i znaki graficzne należą do właścicieli serwisów.

Pliki `icons/*.png` pod wcześniejszymi nazwami pozostają kopiami tych samych oryginałów dla starszych metadanych dodatków. Nowe wersje używają adresów `*-site.png`.

ObejrzyjTo zachowuje oryginalną ikonę i opis pobrane z katalogu Phisher98.

## Własne grafiki repozytorium

`banner.svg` jest banerem README. `icons/repository.svg` i `icons/repository.png` to własny znak Dedziek CloudStream. PNG ma 512 × 512 px; źródło SVG pozostaje edytowalne.
